# Google 日本語入力のローマ字テーブル

`romantable.txt` は、このキーボードで使っている Google 日本語入力のローマ字テーブルです。
キーボード側のキー（キーマップのマクロ）が、ここに登録した打ち方を前提にしています。
PC ごとに読み込む必要があります（キーボードに書き込むファイルではありません）。

## 読み込み方

1. タスクバーの「あ」を右クリック →「プロパティ」→「一般」タブ
2. 「ローマ字テーブル」の「編集」を開く
3. 左下の「編集」→「インポート」で `romantable.txt` を選ぶ
4. 「OK」で閉じる

インポートすると、今のテーブルがこのファイルの内容に置き換わります。

## 標準のテーブルから変えているところ

| 入力 | 出力 | 使っているキー（`config/lalapadgen2.keymap`） |
| --- | --- | --- |
| `z=` | ―（ホリゾンタルバー U+2015） | `sym_hbar_ime` |
| `z-` | ～（全角チルダ U+FF5E。標準は波ダッシュ 〜 U+301C） | `sym_tilde_ime` |
| `z{` | “（U+201C） | `pair_cquote_ime` |
| `z}` | ”（U+201D） | `pair_cquote_ime` |

標準のテーブルにある `z.`（…）、`z[` `z]`（『』）、`[` `]`（「」）も、キーボード側のキー
（`sym_ellipsis`、`pair_nijukagi`、`pair_kagi`、かなの `KN_SANTEN`・`KN_KAGI`）が使っています。

## 登録していない PC では

上の打ち方が登録されていないと、`z=` などがそのまま入力されます。
その場合は、Windows の Alt コードで送る予備のキー（`sym_hbar`・`sym_tilde`・`pair_cquote`）を使えます
（日本語の Windows でだけ動きます）。

## ファイルの形式

UTF-8（BOM なし）、タブ区切り、改行は CRLF。`.gitattributes` で、取り出したときの改行を CRLF に固定しています。
テーブルを変えたときは、Google 日本語入力の「エクスポート」で書き出して、このファイルを置き換えてください。
