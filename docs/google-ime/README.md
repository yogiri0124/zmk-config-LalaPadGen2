# Google 日本語入力のローマ字テーブル・キー設定

このフォルダには、このキーボードで使っている Google 日本語入力の設定を置いています。

- `romantable.txt`: ローマ字テーブル（下の各節）
- `keymap.txt`: キー設定（[キー設定](#キー設定keymaptxt)）
- `kanji.tsv`: 漢字入力の表（`romantable.txt` の漢字の行の元。[漢字の行](#漢字の行-と英字-2-文字)）

`romantable.txt` は、このキーボードで使っている Google 日本語入力のローマ字テーブルです。
キーボード側のキー（キーマップの `sym_`・`pair_` のキー）が、ここに登録した打ち方を前提にしています。
PC ごとに読み込む必要があります（キーボードに書き込むファイルではありません）。

## 読み込み方

1. タスクバーの「あ」を右クリック →「プロパティ」→「一般」タブ
2. 「ローマ字テーブル」の「編集」を開く
3. 左下の「編集」→「インポート」で `romantable.txt` を選ぶ
4. 「OK」で閉じる

インポートすると、今のテーブルがこのファイルの内容に置き換わります。

## 標準のテーブルから変えているところ

| 入力 | 出力 | 使っているキー（`config/lalapadgen2.keymap`） |
| --- | --- | --- |
| `z=` | ―（ホリゾンタルバー U+2015） | `sym_hbar_ime`（2 回送って ―― にする） |
| `z-` | ～（全角チルダ U+FF5E。標準は波ダッシュ 〜 U+301C） | `sym_tilde_ime` |
| `z{` | “（U+201C） | `pair_cquote_ime` |
| `z}` | ”（U+201D） | `pair_cquote_ime` |

標準のテーブルにある `z.`（…）、`z[` `z]`（『』）、`[` `]`（「」）も、キーボード側のキー
（`sym_ellipsis`、`pair_nijukagi`、`pair_kagi`）が使っています。
かなのキー（`&kana_key`。`ka` → か、`xya` → ゃ、`xtu` → っ、`nn` → ん など）と、`ks_` のキーのうち
`ks_touten`・`ks_kuten`・`ks_chouon`（`,` → 、 `.` → 。 `-` → ー）も、標準のテーブルの打ち方を前提にしています。
テーブルを自分で変えるときは、これらの打ち方を消したり変えたりしないでください
（`ks_excl`・`ks_ques` の ！ ？ はテーブルではなく、Google 日本語入力の全角・半角の設定で全角になります）。

## 漢字の行（`;` と英字 2 文字）

`;ab` のように `;` と英字 2 文字で始まる行は、漢字入力（`&kanji_key`）の符号です。手で書かずに、
[kanji.tsv](kanji.tsv) に書いて `python docs/tools/gen_kanji.py` で作ります（漢字の行だけを入れ替えて末尾に並べ、ほかの行はそのまま残します）。
`;` や `;a` のように、符号の途中までと同じ打ち方の行は登録しないでください（符号が漢字にならなくなるため。スクリプトは誤りとして止まります）。

漢字を 1 つでも登録すると、IME オンのときに `;` と英字を続けて打つと（登録した組み合わせなら）漢字になり、
`;` を打った直後は次の文字を待つ表示になります（ふだんの入力で `;` を打つときの注意）。

## 登録していない PC では

上の打ち方が登録されていないと、`z=` などがそのまま入力されます。
漢字入力のキーも、`;ab` などの符号がそのまま入ります。
記号の場合は、Windows の Alt コードで送る予備のキー（`sym_hbar`・`sym_tilde`・`pair_cquote`）を使えます
（日本語の Windows でだけ動きます）。予備のキーは、はじめはどのレイヤーにも置いていないので、
先にエディタ（LaLapad-Gen2-Editor や ZMK Studio）で好きな位置に置いてください。

## キー設定（keymap.txt）

`keymap.txt` は、このキーボードで使っている Google 日本語入力のキー設定です（Google 日本語入力の「エクスポート」で書き出したもの）。
ローマ字テーブルと同じく、PC ごとに読み込みます。

1. タスクバーの「あ」を右クリック →「プロパティ」→「一般」タブ
2. 「キー設定」の「編集」を開く
3. 左下の「編集」→「インポート」で `keymap.txt` を選ぶ
4. 「OK」で閉じる

インポートすると、今のキー設定がこのファイルの内容に置き換わります。

キーボード側に関係する行:

- `ON` → `IMEOn`、`OFF` → `IMEOff`（入力文字なし・変換前入力中・変換中・直接入力の各状態）: キーボードは IME オンに
  `LANGUAGE_1`、IME オフに `LANGUAGE_2` を送る（かなモードの切り替え、記号・漢字のキーの前の IME オンなど）。
- `F13` → `IMEOn`（直接入力のとき）。

キー設定を変えたときは、Google 日本語入力の「エクスポート」で書き出して、このファイルを置き換えてください。

## ファイルの形式

`romantable.txt`・`keymap.txt` とも、UTF-8（BOM なし）、タブ区切り、改行は CRLF。`.gitattributes` で、取り出したときの改行を CRLF に固定しています。
テーブルを変えたときは、Google 日本語入力の「エクスポート」で書き出して、このファイルを置き換えてください
（漢字の行は `kanji.tsv` から `docs/tools/gen_kanji.py` で作るので、手で直さずに表を直してください）。
